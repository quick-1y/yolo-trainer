## Phase Goal

ROADMAP goal (verbatim): "A user can annotate images one by one with bounding boxes in a fast, keyboard-driven editor without ever losing work". This plan delivers the grid side of success criterion 5: progress at a glance and a one-click "Annotate next" (D-16, D-17).

<objective>
The Images page shows how far the project is annotated and offers "Annotate next", which drops the user into the editor on the first image that still needs work.

Purpose: makes the grid the starting point of the annotate loop; the summary keeps unannotated and background distinct (Plan 08 counts).
Output: shared stub helper (Pitfall 13), `StatusSummary`, `AnnotateNextButton`, upload button variant, summary invalidation after uploads/deletes.
</objective>
