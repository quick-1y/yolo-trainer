## Phase Goal

ROADMAP goal (verbatim): "A user can annotate images one by one with bounding boxes in a fast, keyboard-driven editor without ever losing work". This plan delivers "select, move and resize" from success criterion 2.

<objective>
A user can switch between the Select and Box tools, select a box, move it and resize it with the mouse; every completed gesture is one undoable history entry and is autosaved. The Box tool gets its crosshair guides and boxes get their label chips.

Purpose: validates the Konva Transformer edit model (`docs/roadmap.md` §7.3) under the stage scale before polygons build on it (Phase 6).
Output: ToolBar, UI store, interactive BoxShape, Transformer wiring, Crosshair, geometry helpers with tests.
</objective>
