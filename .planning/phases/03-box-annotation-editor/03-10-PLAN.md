## Phase Goal

ROADMAP goal (verbatim): "A user can annotate images one by one with bounding boxes in a fast, keyboard-driven editor without ever losing work". This plan delivers "zooms and pans" (success criterion 1, D-04).

<objective>
A user zooms toward the cursor with the wheel, pans with Space-drag or the middle button, and returns to fit with F, 0 or the overlay; drawing and editing stay exact at any zoom.

Purpose: small objects need zoom to be boxed accurately; the zoom math is the part most likely to drift, so it lives in a pure, unit-tested module (RESEARCH Pattern 5).
Output: `lib/viewport.ts` + tests, `useStageViewport`, wheel/pan handling, `ZoomOverlay`, the fit shortcut.
</objective>
