## Phase Goal

ROADMAP goal (verbatim): "A user can annotate images one by one with bounding boxes in a fast, keyboard-driven editor without ever losing work". This plan delivers "assigns a class to each, and changes the class of an existing box" (success criterion 2) and the right panel of D-02.

<objective>
The right panel comes alive: a class list that sets the active class or reclassifies the selected box (mouse or digit keys), inline class creation when the project has none, and a virtualized object list with per-object class dropdown, visibility toggle and delete.

Purpose: the owner's main loop is "draw many boxes of one class, switch class, continue" (CONTEXT specifics); this plan makes the class the user is drawing with explicit and fast to change.
Output: `ClassPanel`, `ObjectList`, `setBoxClass`, digit shortcuts, hidden/hover sync, tests.
</objective>
