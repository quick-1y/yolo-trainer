## Phase Goal

ROADMAP goal (verbatim): "A user can annotate images one by one with bounding boxes in a fast, keyboard-driven editor without ever losing work". This plan delivers "moves to the next/previous image without returning to the grid" (success criterion 1) and the navigation half of "without ever losing work" (D-11).

<objective>
A user steps through images with the top bar arrows or A/D/←/→ in the grid's order and sees "N of M"; leaving an image always waits for its save, and a failed save is never lost silently.

Purpose: D-03 (grid order that survives a reload) needs a server answer, because the editor cannot hold every grid page; Pitfall 12 (no `useBlocker` under `BrowserRouter`) needs one navigation helper that awaits the saver.
Output: grid-order helpers + neighbors endpoint with tests; top bar navigation; `useEditorNavigation`; `LeaveDialog`; beforeunload guard.
</objective>
