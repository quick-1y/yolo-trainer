## Phase Goal

ROADMAP goal (verbatim): "A user can annotate images one by one with bounding boxes in a fast, keyboard-driven editor without ever losing work". This plan delivers "each image shows a status" on the grid (success criterion 5, D-17).

<objective>
Every grid tile shows its annotation status and box count, and both update the moment an image is saved in the editor, without reloading the grid.

Purpose: the grid is the user's overview of the dataset; D-17 asks for the badge and count there, and RESEARCH Pattern 8 asks that a save never forces a refetch of every loaded page.
Output: widened `ImageItem`, shared `makeImageItem` fixture, tile chip + pill, cache patching after saves, tests.
</objective>
