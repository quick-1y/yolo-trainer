## Phase Goal

ROADMAP goal (verbatim): "A user can annotate images one by one with bounding boxes in a fast, keyboard-driven editor without ever losing work". This plan delivers success criterion 5 inside the editor: status, jump to the next unannotated image, and background.

<objective>
A user sees each image's status in the editor, marks images reviewed or background, and jumps straight to the next unannotated image in grid order. The server gains the next-unannotated and status-counts endpoints the grid uses in Plans 03-09 and 03-11.

Purpose: D-13..D-16 turn the editor into a work queue; keeping "unannotated" and "background" strictly apart protects the training data that Phase 4 exports.
Output: two endpoints with tests; store toggles; top bar badge and buttons; background body in the object list; R/G/N keys.
</objective>
