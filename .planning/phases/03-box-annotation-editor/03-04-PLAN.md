## Phase Goal

ROADMAP goal (verbatim): "A user can annotate images one by one with bounding boxes in a fast, keyboard-driven editor without ever losing work". This plan delivers "opens an image from the grid in the annotation editor" (success criterion 1).

<objective>
A user opens any image from the Images grid straight into the editor, and the grid's sort and search survive the round trip because they live in the URL.

Purpose: D-03 needs the editor and the grid to share one ordering; carrying it in the URL also makes both pages reloadable. The P2 viewer modal is replaced by the editor (P2 D-10).
Output: URL-backed `ImagesPage`, tile navigation, viewer removal, tests.
</objective>
