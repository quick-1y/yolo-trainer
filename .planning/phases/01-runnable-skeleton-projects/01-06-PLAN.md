## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Tampering | heartbeat file | low | mitigate | Fixed path derived from validated settings (`data_dir/worker/heartbeat.json`), atomic `os.replace`, no user input in the path |
| T-06-02 | Information Disclosure / Elevation of Privilege | worker service | medium | mitigate | No `ports:`; reachable only on the compose network; runs no jobs and accepts no input in this phase |
| T-06-03 | Denial of Service | worker shutdown | low | mitigate | SIGTERM handler + `stop_grace_period: 20s`; `STOPSIGNAL SIGTERM` |
| T-06-04 | Information Disclosure | Ultralytics analytics | low | accept | No train/predict calls in Phase 1; SUMMARY records the Phase 4 follow-up to disable analytics before jobs run |
| T-06-SC | Tampering | torch/ultralytics wheels, apt packages | high | mitigate | `uv sync --frozen` from the committed, hashed `uv.lock` (torch/torchvision only from the explicit pytorch-cpu index); apt limited to `libgl1`, `libglib2.0-0` from the official Debian mirrors of `python:3.12-slim` |
