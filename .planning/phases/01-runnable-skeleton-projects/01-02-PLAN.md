## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (any site the user visits) -> api via web | DNS-rebinding pages can make the user's browser call the local, unauthenticated API |
| api container -> host bind mount (DATA_DIR) | Cross-VM filesystem on Docker Desktop; SQLite locking/shared-memory semantics differ |
| .env -> container environment | Host-side configuration controls journal mode and host allow-list |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Spoofing / Elevation of Privilege | main.py (no auth) | medium | mitigate | `TrustedHostMiddleware` with `ALLOWED_HOSTS` default `localhost,127.0.0.1`; test proves a foreign Host gets 400 |
| T-02-02 | Tampering (integrity) | SQLite WAL on Docker Desktop bind mount | high | mitigate | WAL + `synchronous=NORMAL` + `busy_timeout=30000`; `wal_checkpoint(TRUNCATE)` on shutdown; `stop_grace_period: 20s`; `SQLITE_JOURNAL_MODE=DELETE` escape hatch; smoke test burst writes + rebuild + `PRAGMA integrity_check` |
| T-02-03 | Tampering / Denial of Service | settings.validate_data_dir | medium | mitigate | Resolve and require a writable directory at startup; fail fast naming the path instead of writing elsewhere |
| T-02-04 | Tampering (injection) | db.py journal-mode PRAGMA | low | mitigate | Value constrained to `Literal["WAL","DELETE"]` by pydantic before interpolation; never derived from request data |
| T-02-05 | Denial of Service (data loss) | lifespan / migrations | high | mitigate | Startup runs only `alembic upgrade head`; no metadata-level table create/drop or file deletion (acceptance grep); restart no-op test |
