## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> PATCH/DELETE /api/projects/{id} | State-changing, destructive requests with no authentication |
| other web origins -> local API | A malicious page open in the same browser could try cross-origin requests |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-01 | Tampering (mass assignment) | ProjectUpdate | medium | mitigate | `extra="forbid"`; `task_type` explicitly refused (D-09); only `model_fields_set` fields applied |
| T-09-02 | Tampering / Denial of Service (data loss) | DeleteProjectModal | high | mitigate | Exact typed-name confirmation (D-10), single-request submit lock; tests prove disabled states |
| T-09-03 | Spoofing (CSRF from other origins) | PATCH/DELETE | medium | mitigate | No CORS middleware (cross-origin PATCH/DELETE need a preflight the API never approves); FastAPI parses JSON bodies only for JSON content types; Plan 02 Host allow-list blocks DNS rebinding |
| T-09-04 | Repudiation | hard delete | low | accept | Single-operator tool, hard delete by explicit decision D-10; no audit log in v1 |
| T-09-SC | Tampering | @mantine/notifications install | medium | mitigate | Listed and approved in RESEARCH's audit (official mantinedev repo, ~1.6M weekly downloads); lockfile committed |
</threat_model>
