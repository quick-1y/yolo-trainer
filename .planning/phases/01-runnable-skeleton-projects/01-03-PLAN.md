## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | schemas.ProjectName | medium | mitigate | NFC + trim + code-point length + control-character rejection; `extra="forbid"`; server is the authority, client checks are UX only |
| T-03-02 | Spoofing (look-alike names) | normalize_project_name | low | mitigate | NFKC + casefold uniqueness so compatibility/case variants collide; DB unique index is the final guard |
| T-03-03 | Tampering (stored XSS) | CreateProjectModal / ProjectCard rendering API detail and names | medium | mitigate | Render as React text nodes only; no `dangerouslySetInnerHTML`; nginx CSP from Plan 01 |
| T-03-04 | Denial of Service | double-submit | low | mitigate | Pending-state submit lock; DB uniqueness makes repeats return 409 instead of duplicates |
| T-03-SC | Tampering | npm devDependencies | high | mitigate | Only vitest, jsdom, @testing-library/{react,dom,jest-dom,user-event} — registry, repo and weekly downloads verified 2026-09-24 (tens of millions/week, official GitHub orgs); lockfile committed |
