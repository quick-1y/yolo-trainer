## Phase Goal

ROADMAP goal (verbatim, not in user-story form): "A user can annotate `segment` projects with polygons, drawn by hand or generated with one click, and train segmentation models end-to-end". No story is invented; run `/gsd-mvp-phase 6` if one is wanted.

<objective>
The server makes each project's geometry homogeneous and keeps it that way: a one-time migration turns the boxes of segment projects into 4-point polygons (D-09, one-way), and every save of the wrong kind is refused with a plain 422 before anything changes (D-12, costly).

Purpose: success criterion 3 ("the server refuses geometry that violates the project's task type") and the guarantee Ultralytics needs (a segment dataset must not mix box and polygon rows, Phase 0 §3). Plan 06-16 already makes the editor send only polygons in segment projects and Plan 06-05 moved the test helpers to polygons, so this refusal never fires on normal use.
Output: confirmation checkpoint for the one-way D-09 door, migration 0011 with tests, the pre-CAS kind check, updated tests.
</objective>
