## Phase Goal

ROADMAP goal (verbatim, not in user-story form): "A user can annotate `segment` projects with polygons, drawn by hand or generated with one click, and train segmentation models end-to-end". No story is invented; run `/gsd-mvp-phase 6` if one is wanted.

Token estimate: 120000 (uncalibrated, confidence low), above the 100000 smart-zone budget; advisory only.

<objective>
A user selects a polygon and edits it the Label Studio / CVAT way (D-02): drags vertices, adds a vertex from a faded midpoint handle, deletes a vertex with Alt+click or right-click (never below 3), moves the whole polygon, changes its class and deletes it — each as one undoable gesture.

Purpose: completes success criterion 1 ("edits it by adding, moving, and deleting vertices, and assigns a class"), and makes click-to-segment results editable like hand-drawn shapes (success criterion 2, Plan 06-08).
Output: interactive `PolygonShape`, vertex helpers, store actions, selection wiring, gesture rows.
</objective>
