## Phase Goal

ROADMAP goal (verbatim, not in user-story form): "A user can annotate `segment` projects with polygons, drawn by hand or generated with one click, and train segmentation models end-to-end". No story is invented; run `/gsd-mvp-phase 6` if one is wanted.

Scope note: token estimate 75000 (uncalibrated, confidence low). 10 files. Split out of the former 11-file, 115000-token Plan 06-11 at its Task 1 / Task 2 seam: this plan carries the box metrics of segment runs from Python to the browser and draws the mAP chart with them; Plan 06-23 adds the precision/recall pair, the loss breakdown without `sem` and the tooltip. The plan lists ANNO-11 because success criterion 4 ("a segment project ... trains end-to-end, and its live charts show mask metrics") has no requirement id of its own; it is the training face of the segment task type.

<objective>
While a segment model trains, the user watches mask mAP as the primary solid lines and box mAP as dashed companions on the mAP chart, fed by `secondary` frames whose keys are mapped in Python and checked against the real captured run (D-13).

Purpose: success criterion 4's chart half, built on the keys captured from the real segment run (Plan 06-24), not on guesses. Plan 06-23 completes the other two charts; Plan 06-12 uses `secondary_metrics` and `finalSecondary` for the results card.
Output: `secondary_metrics` and `secondary` frames, fold support for box fields, the segment mAP series and caption, a frontend fixture of the captured run.
</objective>
