## Phase Goal

ROADMAP goal (verbatim, not in user-story form): "A user can annotate `segment` projects with polygons, drawn by hand or generated with one click, and train segmentation models end-to-end". No story is invented; run `/gsd-mvp-phase 6` if one is wanted.

## Slice note

This plan is the click-to-segment stream's own end-to-end slice through the server tiers (api route -> client -> HTTP -> segmenter app -> engine seam) and stops at the public API that the browser client of Plan 06-18 and the tool of Plan 06-08 call. The engine is injectable here; Plan 06-17 fills in the real MobileSAM engine behind the same seam and makes the worker container run the segmenter process (a stub filled later without an architectural change). It runs in Wave 1 next to the polygon tracer because it shares no file with it. 10 files; token estimate 95000 (uncalibrated, confidence low).

<objective>
A click-to-segment request goes from the api over HTTP to the segmenter service and comes back as a contour, with the project and image checked first, only integers crossing the wire, and every failure mapped to a plain message.

Purpose: ANNO-05's server contract, D-07 (outside the training queue) and the api's torch-free rule (P1 D-17).
Output: layout helpers, the segmenter app and engine seam, the api client and routes, settings, tests.
</objective>
