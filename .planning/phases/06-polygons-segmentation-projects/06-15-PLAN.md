## Phase Goal

<objective>
In a segment project the user picks the Polygon tool, clicks vertices, closes the contour on its first vertex, and the polygon is saved by autosave and comes back after a reload; a detect project never offers the tool.

Purpose: completes the tracer path end-to-end through the user's own entry point (Plans 06-01 and 06-14 carried the server and browser data halves) and makes the tool bar follow the project task type (ANNO-11, D-10).
Output: `EditorTool` "polygon", `PolygonDraft`, canvas draft handling, Polygon tool button and icon, task-type-aware tool bar, tests.
</objective>
