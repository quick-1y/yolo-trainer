## Phase Goal

ROADMAP goal (verbatim, not in user-story form): "A user can annotate `segment` projects with polygons, drawn by hand or generated with one click, and train segmentation models end-to-end". No story is invented; run `/gsd-mvp-phase 6` if one is wanted.

## Scope note

The browser half of click-to-segment needs about 17 files at once (Plan 06-08 before this revision). Its pure, I/O-defined logic — the api client, the request loop (a small state machine) and the outline simplification (an algorithm) — is carved out here as task-level TDD work, so the tool plans (06-08, 06-19) stay within the file budget. It is file-disjoint from the polygon editor plans: the simplification lives in `lib/simplify.ts`, not `lib/polygon.ts`, so this plan runs in Wave 2 next to Plan 06-14. The user sees its effect from Plan 06-08 on. 7 files; token estimate 70000 (uncalibrated, confidence low).
