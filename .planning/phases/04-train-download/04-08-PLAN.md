## Phase Goal

ROADMAP goal (verbatim): "A user can turn an annotated project into a trained model from the browser and download a `.pt` the downstream project can load, completing the upload → annotate → train → download loop". This plan completes success criteria 1 and 2 in the start form: "a run cannot start while train or valid is empty, and the UI explains why" and "the base is either an official Ultralytics pretrained model ... or a model previously trained in this service". No user story is invented.

<objective>
Before starting, the user sees what the run will train on and why it cannot start yet (with one-click fixes), and can fine-tune from a model trained earlier in this service.

Purpose: D-04, D-05, D-06, D-08, D-10 complete on top of the Plan 04-02 form, the Plan 04-06 auto-split dialog and the Plan 04-01 create contract.
Output: summary/blockers/warnings/models in the options, trained-model bases end to end (API, worker), the run-creation contract tests, `DatasetSummary`, `DatasetNotes`, the two-column form, i18n and tests.
</objective>
