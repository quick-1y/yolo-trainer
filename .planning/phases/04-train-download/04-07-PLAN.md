## Phase Goal

ROADMAP goal (verbatim): "A user can turn an annotated project into a trained model from the browser and download a `.pt` the downstream project can load, completing the upload → annotate → train → download loop". This plan completes the run page for every status (D-11..D-15) and shows each run's frozen settings (success criterion 5). No user story is invented.

<objective>
A user understands every run from its page: why it failed (message and log), that it was interrupted by a restart, what settings and dataset it used, and can take a queued run back out of the queue; and the `.pt` download contract is pinned by tests.

Purpose: completes D-11 (queue removal), D-13 (interrupted view), D-15 (failure view), the TRAN-03 settings display and MODL-04's download contract on top of Plan 04-02's run page.
Output: DELETE route + tests, download tests, `RunSettingsCard`, `RunFailureLog`, `RemoveFromQueueModal`, RunPage status cards for failed/interrupted/cancelled, i18n and tests.
</objective>
