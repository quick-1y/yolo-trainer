Run `/gsd-mvp-phase 4` if a formal "**As a** / **I want to** / **so that**" story is wanted; none is invented here.

<objective>
Tracer for Phase 4: the thinnest real path "assign splits -> POST a run -> the api snapshots the project in the INSERT transaction and materializes a hard-linked YOLO dataset -> the worker container claims the queued run from SQLite -> a `train_job` subprocess trains with Ultralytics callbacks writing JSONL -> the supervisor registers best.pt as a model -> the user downloads a `.pt` that loads with plain `YOLO(path)`", wired end-to-end through nginx and proven by the compose smoke test plus a fast in-process pipeline test with a fake trainer.

## Assumptions (edge probe, unresolved — flagged, not truths)

The spec-less edge probe left four requirement rows unclassified. They are carried as explicit assumptions for review, not silently dropped:
