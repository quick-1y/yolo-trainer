## Phase Goal

ROADMAP goal (verbatim): "A user can turn an annotated project into a trained model from the browser and download a `.pt` the downstream project can load, completing the upload → annotate → train → download loop". This plan delivers manual split assignment (success criterion 1, first half; DATA-05). No user story is invented.

<objective>
A user assigns images to Train, Valid, Test or back to no split, by hand: many at once from a grid selection, or the current image from the editor top bar, and sees each image's split on its tile and the per-split counts under the grid.

Purpose: DATA-05 manual assignment (D-02) without touching annotation state, on top of the Plan 04-01 split route and split counts. Auto-split is Plan 04-06.
Output: route contract tests, `api/splits.ts`, `SplitMenu`, tile pill, summary line, selection-bar action, editor split menu, i18n and tests.
</objective>
