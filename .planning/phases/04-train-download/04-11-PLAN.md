## Phase Goal

ROADMAP goal (verbatim): "A user can turn an annotated project into a trained model from the browser and download a `.pt` the downstream project can load, completing the upload → annotate → train → download loop". This plan closes the phase: the downstream-style `.pt` check, the documentation, the full-suite gate and the end-of-phase checklist. No user story is invented.
