## Phase Goal

ROADMAP goal (verbatim): "A user can turn an annotated project into a trained model from the browser and download a `.pt` the downstream project can load, completing the upload → annotate → train → download loop". This plan makes a background run visible everywhere (D-14), so annotating while a run trains is a first-class workflow. No user story is invented.

<objective>
Wherever the user is, including the full-screen editor, they see that a training run is in progress, which one and how far it is, and can jump to it in one click without losing unsaved annotation work.

Purpose: D-14 and the TRAN-04 "UI stays responsive / reopening shows the current status" experience across the app.
Output: `GET /api/training/active`, `useActiveRun`, `ActiveRunIndicator` (header and editor forms), sidebar Loader, the test-harness opt-in for the poller, i18n and tests.
</objective>
