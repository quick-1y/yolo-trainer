## Phase Goal

ROADMAP goal (verbatim): "A user can turn an annotated project into a trained model from the browser and download a `.pt` the downstream project can load, completing the upload → annotate → train → download loop". This plan makes success criterion 5 provable: "Each run stores a snapshot of its settings and the exact dataset (images, labels, splits, classes) it trained on; later annotation edits do not change what the run records it was trained with". No user story is invented.

<objective>
Every run's dataset snapshot is exactly what the project held when Start was pressed, is a valid Ultralytics dataset for detect and segment projects, and stays unchanged no matter what happens to the project afterwards.

Purpose: TRAN-03 and D-19/D-20 are a reproducibility contract (rated costly) that Phase 5 resume, Phase 9 export and Phase 11 evaluation read; this plan pins it with tests and fixes whatever the tests expose in `labels.py` / `snapshot.py`.
Output: `test_training_labels.py`, `test_training_snapshot.py`, a 0004 -> head migration test, and any fixes.
</objective>
