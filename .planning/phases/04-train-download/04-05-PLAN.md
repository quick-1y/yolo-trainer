## Phase Goal

ROADMAP goal (verbatim): "A user can turn an annotated project into a trained model from the browser and download a `.pt` the downstream project can load, completing the upload → annotate → train → download loop". This plan makes success criterion 3 hold under restarts: "Training runs in a background worker: the UI stays responsive, closing the browser does not stop the run, reopening shows its current status, and restarting the backend mid-run marks the run interrupted instead of losing track of it". No user story is invented.

<objective>
Runs survive every restart pattern with an honest status: the queue keeps its order, a restarted worker or api never leaves a run stuck in 'running', a stop signal ends the training process cleanly, failures carry a readable message and log tail, and a real CPU training proves the callback stream and the downloadable model.

Purpose: TRAN-04 robustness (D-11, D-13, D-15) and the real-Ultralytics proof for MODL-01/MODL-03 that the fake trainer cannot give.
Output: api startup sweep, heartbeat `active_run_id`, hardened stop/failure handling, progress helper tests, queue tests, supervisor tests, and the `training` marker with a real CPU training test.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| docker stop/restart -> worker | signals and restarts while a child process trains |
| heartbeat file -> api sweep | the api decides interruption from a file the worker writes |
| train.log -> run row -> UI | untrusted process output becomes stored text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T4-05-01 | Denial of Service (orphan process) | supervisor stop | medium | mitigate | Process group terminate then kill within 10 s; test proves the child exits |
| T4-05-02 | Tampering (wrong kill) | reconcile_on_start | high | mitigate | Never signal a recorded PID (namespace reuse); grep gate on os.kill |
| T4-05-03 | Repudiation (lost run state) | api/worker sweeps | medium | mitigate | preparing -> failed, running -> interrupted with explicit messages; fresh-heartbeat rule avoids false interrupts |
| T4-05-04 | Tampering (stored XSS via log) | log_tail | medium | mitigate | ANSI stripped, stored as text, rendered as text in Plan 04-07 (T4-08) |
| T4-05-05 | Information Disclosure (telemetry) | train_job | medium | mitigate | `configure_ultralytics` sets sync false first; test reads the isolated settings file |
| T4-05-06 | Tampering (integrity) | register_model failure | medium | mitigate | Rollback + file removal; test proves no row and no file |
</threat_model>
