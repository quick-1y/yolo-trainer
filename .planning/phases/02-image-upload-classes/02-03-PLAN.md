## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T2-03-01 | Denial of Service | process_image (pixel bombs, huge files) | high | mitigate | Header pixel cap before decode and per-file byte cap during staging, both covered by tests (pixel cap with max_pixels=1000; size cap with MAX_UPLOAD_MB=1) |
| T2-03-02 | Tampering | corrupt / truncated / polyglot files | high | mitigate | Full `load()` decode is the validity check; truncated JPEG and PNG cases tested; unsupported formats (GIF, TIFF) rejected by decoded format |
| T2-03-03 | Tampering | filename handling | medium | mitigate | `clean_filename` unit-tested against separators, escapes, control characters and length; filesystem paths never use the name (Plan 01) |
| T2-03-04 | Tampering (integrity) | duplicate race / project delete race | medium | mitigate | `UNIQUE(project_id, sha256)` + IntegrityError branch tested with 8 concurrent uploads; FK failure path tested to leave no files |
| T2-03-05 | Elevation of Privilege | Pillow decoder vulnerabilities | medium | mitigate | Pillow pinned `>=12.3,<13` from the hashed lockfile; only five allow-listed formats are ever decoded past the header (RESEARCH A9) |
