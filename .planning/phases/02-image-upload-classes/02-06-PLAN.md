## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local filesystem -> browser | the user picks arbitrary files and folders (names and sizes are untrusted) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T2-06-01 | Denial of Service (client) | upload state with thousands of files | medium | mitigate | Counters-only state updated once per batch; rejected list rendered capped at 100 rows inside a collapsed ScrollArea |
| T2-06-02 | Denial of Service (server) | request fan-out | medium | mitigate | Batches of at most 10 files / max_upload_bytes and concurrency 3; server still enforces per-file limits and nginx the body cap |
| T2-06-03 | Tampering (stored XSS) | rejected list filenames and server reasons | medium | mitigate | Rendered as React text with native `title`; copied text is plain text via CopyButton |
| T2-06-04 | Spoofing (CSRF) | batched POSTs | high | mitigate | Requests go through `apiRequest`, which always sends X-Requested-With; the api's `require_xhr` still rejects header-less cross-site posts |
| T2-06-05 | Information Disclosure | GET /api/config | low | accept | Exposes only upload limits and accepted extensions, which the UI displays anyway |
</threat_model>
