## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> api (image id path params) | ids in the URL are client-controlled |
| api -> browser (original bytes) | stored originals are user-supplied content served back to the browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T2-10-01 | Information Disclosure | GET /file | medium | mitigate | Row lookup by id AND project_id (404 across projects, tested); path built from integers via `image_path` |
| T2-10-02 | Tampering (content sniffing / polyglot) | original file delivery | high | mitigate | Only decoded-and-validated files are stored (Plan 01/03); media type fixed from the CHECK-constrained `ext`; nginx server-level nosniff; rendered only via `<img>` |
| T2-10-03 | Tampering (XSS) | viewer header filename | low | mitigate | React text plus native `title`; no HTML injection |
</threat_model>
